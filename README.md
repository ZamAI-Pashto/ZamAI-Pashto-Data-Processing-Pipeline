# ZamAI Pashto Datasets

A central repository by ZamAI for storing and curating Pashto datasets. This collection supports research, development, and fine-tuning of AI and machine learning models, with a focus on data quality and reproducibility.

## Overview

- **High-quality Pashto datasets** for natural language processing and AI tasks
- Documentation and metadata for each dataset
- Open for contributions and collaborative dataset curation
